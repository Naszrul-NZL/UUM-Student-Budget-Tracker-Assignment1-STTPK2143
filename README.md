# UUM Student Budget Tracker

UUM Student Budget Tracker is a simple Flutter application developed for Assignment 1 of `STTPK2143`. The app helps students monitor their weekly spending by comparing a planned budget with the total amount already spent.

## Project Overview

This application is designed as a lightweight budget calculator for students. Users can enter a weekly budget, add expense amounts, and instantly view:

- Remaining balance
- Total amount spent
- Updated values after each calculation

## Features

- Add expense values and track cumulative spending
- Calculate the remaining balance instantly
- Display the total amount spent

## How to Run

1. Make sure Flutter is installed and configured on your machine.
2. Open a terminal in the project folder.
3. Navigate to the Flutter app directory:

    cd uumstudent_budgettracker

4. Install dependencies:

    flutter pub get

5. Run the application:

    flutter run

## How to Use

1. Enter your weekly budget.
2. Enter an expense amount.
3. Press the `Calculate` button.
4. View the updated total spent and remaining balance.

## Notes

- Expenses are accumulated each time the `Calculate` button is pressed.
- The current version focuses on basic budget tracking and does not store data permanently.
